# دوري بروكي الفانتازي — الموسم الثاني
### Brookie Fantasy League — Season 2

تطبيق ويب من صفحة واحدة (`index.html`) لمتابعة دوري بروكي للفانتازي: ترتيب عام، كرت بطل الجولة، سجل الجولات بالتفصيل، أداء الأندية، واللائحة الرسمية.

A single-page fantasy-football tracker (`index.html`) for Brookie Fantasy League: live standings, a shareable "round champion" card, a detailed round-by-round history, club performance stats, and the official rulebook.

## التشغيل / Usage

افتح `index.html` مباشرة في أي متصفح — لا حاجة لأي تثبيت أو خادم.

Just open `index.html` in any browser — no build step or server required.

رمز دخول المنظم (تبويب "المنظم"): `2580`

Admin PIN (for the "المنظم" organizer tab): `2580`

## الملفات / Files

- **`index.html`** — التطبيق كاملًا (HTML/CSS/JS في ملف واحد). The full app (HTML/CSS/JS, single file).
- **`دوري-بروكي-ملف-التسليم.md`** — ملف التسليم التقني الكامل: القرارات، مصادر البيانات، الأخطاء المُصلحة، والبحث الذي بُنيت عليه بعض الأرقام (مثل تفاصيل مباريات الجولة 2). A full technical handover doc: decisions made, data sources, fixed bugs, and the research behind some of the numbers (e.g. round-2 match-by-match detail).

## مصدر البيانات / Data sources

بيانات الأندية والمباريات مأخوذة من نتائج حقيقية عبر [365Scores](https://www.365scores.com)، بنظام نقاط فوز=3 / تعادل=1 / خسارة=0 لدوري كل نادٍ المحلي فقط.

Club and match data is sourced from real results via [365Scores](https://www.365scores.com), using a win=3 / draw=1 / loss=0 points system for each club's domestic league only.
