# مواصفات دوري بروكي — Spec-Driven Development

هذا المجلد هو **المرجع الوحيد** لأي تطوير في المشروع. أي شغل، سواء نفّذه Claude أو Codex أو أنت، يبدأ من ملف هنا وينتهي بتحقق مكتوب هنا.

## المنهجية: 4 مراحل، ولا ننتقل لمرحلة قبل اعتماد اللي قبلها

| المرحلة | الملف | السؤال اللي يجاوب عليه | من يعتمده |
|---|---|---|---|
| 0. الدستور | `constitution.md` | وش المبادئ اللي ما نكسرها أبدًا؟ | المنظّم (مرة واحدة) |
| 1. المواصفات | `NNN-*/spec.md` | **وش** نبي و**ليش**؟ (بدون أي تفاصيل تقنية) | المنظّم |
| 2. الخطة | `NNN-*/plan.md` | **كيف** بننفذها تقنيًا؟ وش الملفات اللي بتتأثر؟ | Claude يكتب، والمنظّم يراجع |
| 3. المهام | `NNN-*/tasks.md` | مهام صغيرة مرقّمة، لكل وحدة منفذ ومعيار قبول | تُنفَّذ واحدة واحدة |

**قاعدة ذهبية:** لو اكتشفنا أثناء التنفيذ أن المواصفة غلط أو ناقصة، **نعدّل المواصفة أولًا** ثم الكود. الكود يتبع المواصفة، والعكس ممنوع.

## الخريطة

- `constitution.md`: مبادئ المشروع الثابتة.
- `roadmap.md`: كل المزايا (Features) مرتبة بالأولوية.
- `001-ui-visual-overhaul/`: **الميزة الحالية**، إصلاح الرسومات والواجهة.
  - `spec.md`: المشاكل المرصودة ومتطلبات القبول.
  - `plan.md`: الحل التقني (نظام التصميم، الأيقونات، الشعارات، الكروت).
  - `tasks.md`: المهام المرقّمة مع المنفذ (Claude / Codex).
  - `codex-briefs.md`: أوامر جاهزة تُنسخ لكودكس كما هي.
  - `baseline/`: صور "قبل" الملتقطة 29 أكتوبر 2026، للمقارنة.

## توزيع الأدوار

| الدور | المسؤولية |
|---|---|
| **المنظّم (أنت)** | يعتمد كل `spec.md`، ويقرر الذوق البصري، ويعمل الدمج النهائي |
| **Claude** | يكتب المواصفات والخطط والمهام، وينفذ البنية (الرموز، المحرك، الدمج)، ويراجع مخرجات Codex بصريًا وتقنيًا |
| **Codex** | منفذ **الرسومات**: أيقونات SVG، شعارات الأندية، قوالب الكروت، والخلفيات، حسب `codex-briefs.md` حرفيًا |

## دورة العمل لكل مهمة

```
1. اختر المهمة التالية من tasks.md (اللي كل اعتمادياتها ✅)
2. افتح فرع:  feat/NNN-Txx-وصف-قصير
3. نفّذ (لو المنفذ Codex: انسخ الأمر من codex-briefs.md)
4. شغّل التحقق:  node tests/run.js  +  node tools/snap.js  (بعد المهمة T01)
5. قارن صور "بعد" مع baseline/، وطابق معايير القبول في المهمة
6. علّم المهمة ✅ في tasks.md، ثم Pull Request
```
