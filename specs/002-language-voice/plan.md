## 2. `ar-format.js`: القواعد

### `formatCount(n, noun, opts)`
```js
formatCount(0, 'نقطة')                → 'بلا نقاط'        // opts.zero يغيّرها: 'صفر' ، '0 نقطة'
formatCount(1, 'نقطة')                → 'نقطة واحدة'      // opts.bareOne:true → 'نقطة'
formatCount(2, 'نقطة')                → 'نقطتان'          // opts.case:'acc' → 'نقطتين' (بعد حرف جر أو مفعول)
formatCount(5, 'نقطة')                → '5 نقاط'
formatCount(15, 'مركز')               → '15 مركزًا'        // تمييز منصوب منوّن
formatCount(100, 'مركز')              → '100 مركز'         // مئة: تمييز مجرور
formatCount(103, 'نقطة')              → '103 نقاط'         // ≥100: تُحسب بآخر رقمين
formatCount(111, 'هدف')               → '111 هدفًا'
```

**القاعدة (n ≥ 0):**

| الحالة | الصيغة |
|---|---|
| `n = 0` | `opts.zero` أو "بلا + الجمع" |
| `n = 1` | المفرد + "واحد/واحدة" حسب الجنس |
| `n = 2` | المثنى: رفع (`-ان`) أو نصب وجر (`-ين`) حسب `opts.case` |
| `3–10` | "n + الجمع" |
| `11–99` | "n + المفرد المنصوب" (منوّن إن كان يقبل التنوين) |
| `n ≥ 100` | `r = n % 100`: لو `r = 0` "n + المفرد المجرور"، ولو `r` بين 1 و2 "n + المفرد المجرور"، وإلا نفس قاعدة `r` |

**جدول المعدودات** `NOUNS` (من `glossary.md`):
```js
'نقطة':  {g:'f', one:'نقطة', dual:['نقطتان','نقطتين'], plural:'نقاط', acc:'نقطة'},
'مركز':  {g:'m', one:'مركز', dual:['مركزان','مركزين'], plural:'مراكز', acc:'مركزًا'},
'جولة':  {g:'f', …}, 'مشارك':{…}, 'ممة':{…}, 'نادٍ':{…}, 'دوري':{…}, 'هدف':{…}, 'مباراة':{…}
```
معدود غير موجود في الجدول **يرمي خطأ** وقت التطوير، فما يمر بصمت.

### `pickForm(count, forms)`: مطابقة الفعل والضمير
```js
pickForm(names.length, {one:'سجّل', two:'سجّلا', many:'سجّلوا'})
// L-02: "أبو صالح سجّل" / "أبو صالح وأيوب سجّلا" / "… سجّلوا"
```

### `formatList(names, {max=3})`
```js
['أ']            → 'أ'
['أ','ب']        → 'أ وب'
['أ','ب','ج']    → 'أ، وب، وج'
6 أسماء          → 'أ، وب، وج، و3 آخرون'   // يستخدم formatCount داخليًا
```

### `formatDate(d, {style})`
| `style` | المخرج | الاستخدام |
|---|---|---|
| `full` | 29 أكتوبر 2026 · 18 جمادى الأولى 1448 هـ | الشهادة، والكروت، والأرشيف |
| `short` | 29 أكتوبر | الجداول، وتواريخ المباريات |
| `datetime` | 29 أكتوبر · 9:30 م | الإشعارات، وآخر تحديث |
| `relative` | قبل ساعتين | "آخر تحديث" (يستخدم `formatCount` للوحدات) |

- **التنفيذ:** `Intl.DateTimeFormat` بـ`ar-u-nu-latn` للميلادي، و`ar-SA-u-ca-islamic-umalqura-nu-latn` للهجري، **وبدون مكتبات**.
- **المنطقة الزمنية:** ثابتة `Asia/Riyadh`، فالتاريخ ما يختلف حسب جهاز الزائر.

## 3. محرك الصوت

### بنية القالب (`js/voice/banter.js`)
```js
const BANTER = {
  hero:      [ c => `${c.name} …`, … ],   // ≥ 8 لكل موقف
  mumma:     [ c => `${c.names} ${c.verb({one:'طلع',two:'طلعا',many:'طلعوا'})} بممة …`, … ],
  climber:   [ … ], dropper: [ … ], leader: [ … ], bottom: [ … ], tie: [ … ], duel: [ … ],
};
// السياق c يحمل: الأسماء، والأرقام مصاغة مسبقًا (c.pts = formatCount(…))، و c.verb(...)
// فالقالب نفسه ما يحتاج يتعامل مع قواعد العدد
```

### الاختيار (`voice-engine.js`)
- **حتمي:** `hash(seasonId, roundNumber, situation, personId)` ← نفس النص لكل الزوار في نفس الجولة (مثل السلوك الحالي).
- **بلا تكرار:** لو القالب المختار هو نفسه اللي طلع لنفس الشخص في نفس الموقف بالجولة السابقة، يُختار التالي.
- **الطبقات:** المولّد الرسمي (مثل `buildRoundStory` للواتساب) ما يستدعي `BANTER` أبدًا. والطبقة الشعبية في دوال منفصلة (R-03: الملخص = خبر رسمي + سطر طقطقة منفصل).

## 4. قواعد الفحص المضافة لـ`lint.js`
| القاعدة | تمنع |
|---|---|
| `numberNoun` | `${…} نقطة` وأخواتها خارج `ar-format.js` |
| `rawDates` | `toLocaleDateString` و`toLocaleString` خارج `ar-format.js` |
| `forbiddenTerms` | "المتسابق"، و"اللاعب" (بمعنى المشارك)، و"رصيد" بجوار "الجولة"… في النصوص |
| `hardcodedCounts` | أرقام مكتوبة داخل نص عربي في ملفات الميزات، مثل "13 دوريًا" |

## 5. الترحيل (بالأولوية حسب الانتشار)
1. **ما يوصل الواتساب:** ملخص الواتساب (`standings-table.js`) والكروت.
2. **الصفحة الأولى:** قصة الجولة، والودجتات، و"حالتي".
3. **باقي التبويبات:** الجولات، والإحصائيات، وعن الدوري (قصة الموسم).
4. **لوحة المنظّم و`report.html`.**
