# معجم دوري بروكي الموحّد

> ملزم لكل نص في الموقع والكروت والملخصات (الدستور 15).
> **[قرار Claude]** يعني اختاره Claude بتفويض المنظّم (Q-13…15)، ويقدر المنظّم يغيّره.

## المصطلحات الأساسية

| المفهوم | المعتمد ✅ | الممنوع ❌ | ملاحظة |
|---|---|---|---|
| الشخص في الدوري | **المشارك** / المشاركون | المتسابق، اللاعب | [قرار Claude]. "اللاعب" يلتبس بلاعبي الأندية |
| ما يحصده في جولة | **نقاط الجولة** | رصيد الجولة، حصاد (في الطبقة الرسمية) | [قرار Claude]. "حصاد" مسموح في الطبقة الشعبية فقط |
| المجموع التراكمي | **الرصيد** | المجموع، النقاط الكلية | [قرار Claude] |
| جولة بلا نقاط | **ممة**، والجمع **ممّات** | صفر نقاط، خالي النقاط (في العناوين) | [قرار Claude]. في اللائحة تُعرَّف: "الممة: خروج المشارك بلا أي نقطة في الجولة" |
| الجولة | **الجولة 3** | ج3، ج 3، الجوله | "ج3" مسموحة فقط في رؤوس الأعمدة الضيقة |
| أفضل مشارك في الجولة | **بطل الجولة** | متصدر الجولة، نجم الجولة | |
| الأول في الترتيب | **المتصدر** | الأول، صاحب الصدارة | |
| بطل الموسم | **بطل الموسم** / **حامل اللقب** | | "حامل اللقب" للموسم الحالي عن بطل الموسم الماضي |
| الأندية الثلاثة للمشارك | **أنديته** / **أنديتي** | فرقه، تشكيلته | |
| التغير في الترتيب | **صعد / تراجع X مراكز** | قفز، نزل (في الطبقة الرسمية) | "قفز" و"طاح" مسموحة في الطبقة الشعبية |
| كسر التعادل | **كسر التعادل** | حسم، فك التعادل | |
| المواجهة العشوائية | **مواجهة الجولة** | تحدي الجولة، نزال الجولة | "نزال الموسم" اسم ميزة مستقلة يبقى كما هو |

## المعدودات المدعومة في `formatCount`

| المعدود | 1 | 2 | 3–10 | 11+ |

| نقطة | نقطة واحدة | نقطتان | نقاط | نقطة |
| مركز | مركز واحد | مركزان | مراكز | مركزًا |
| جولة | جولة واحدة | جولتان | جولات | جولة |
| مشارك | مشارك واحد | مشاركان | مشاركين | مشاركًا |
| ممة | ممة واحدة | ممّتان | ممّات | ممة |
| نادٍ | نادٍ واحد | ناديان | أندية | ناديًا |
| دوري | دوري واحد | دوريان | دوريات | دوريًا |
