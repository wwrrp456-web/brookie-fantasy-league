## 3. القرارات
| # | القرار | السبب |
|---|---|---|
| D1 | الأصول ملفات SVG، **وتُولَّد منها نسخة JS** مرفوعة في git (`js/generated/assets.js`) | الكانفس يحتاج data URLs عشان ما "يتلوث" ويفشل التصدير، والموقع يبقى بدون بناء وقت التشغيل |
| D2 | **تحسين الشعارات لا استبدالها** (Q-20): أول خطوة تصدير الشعارات الحالية كملفات كما هي (`export-crests.js`)، ثم Codex يحسّن كل ملف | يحافظ على شغل المنظّم وذوقه، والفرق قابل للمراجعة شعارًا شعارًا |
| D3 | **الأيقونات الـ11 تُحوَّل لمتجهات بأمانة** (نفس الشكل، بدون إعادة تصميم) | تختفي PNG وbase64، وتنرسم حادة على أي حجم |
| D4 | **مصدرا الشعار:** `crestHTML()` تبحث أولًا في `CRESTS_OFFICIAL` (من `assets/crests/official/`)، ثم المحسّن، ثم درع احتياطي من `CLUB_STYLE` | قرار الشعارات الرسمية يبقى بيد المنظّم بدون برمجة (R-04) |
| D5 | الأيقونات خطية على شبكة 24 (`stroke-width:1.75`، `currentColor`، ≤ مسارين) | تتلون مع الثيم، وتُرسم في الكانفس بـ`Path2D` |
| D6 | الكروت **داكنة دائمًا**: 1080×1350 (منشور)، و1080×1920 (ستوري)، و1080×1080 (مربع) | هوية ثابتة في المجموعة، ومقاسات قياسية |
| D7 | خلفيات الكروت وإطار الشهادة الذهبي **صور مولّدة** (WebP ≤ 120KB) | Codex يولّد صور (Q-26)، والزخرفة أجمل من رسمها بالكود |

| D9 | الانتقال **تدريجي** (Strangler): المتغيرات القديمة تصير أسماء بديلة للجديدة، ثم تُحذف | كل PR صغير وقابل للتراجع |
| D10 | **كل نص جديد** يمر على `formatCount` و`formatDate` والمعجم من 002 | ما نرجع نصلح مرتين |

## 6. محرك الكروت
```js
const card = await createCard({format:'post'|'story'|'square', bg:'post'});
card.safe                                   // المنطقة الآمنة، والتذييل خارجها دائمًا
card.text(str,{x,y,maxW,size,weight,color,align,minSize,maxLines})  // تقليص ثم التفاف متوازن بلا يتيمة
card.icon(name,x,y,size,color); card.crest(club,x,y,size); card.statRow([...],y)
validateCardData(kind,data)                 // [] أو قائمة نواقص بالعربية، والكرت ما يُرسم لو فيه نواقص
await document.fonts.load('800 40px Tajawal')  // قبل أي رسم
```
**الكروت الثمانية** (FR-06): البطل، والترتيب، والستوري، وملخص الموسم، والملف الشخصي، والشهادة، و🆕 مواجهة الجولة، و🆕 نتائج أنديتي.

- **"نتائج أنديتي":** من مدخلات آخر جولة مكتملة (`round.entries[pid]`)، ولا تعتمد على 005.
- **"مواجهة الجولة":** من بيانات المواجهات العشوائية الموجودة.
