## 2. المعمارية المستهدفة

```
assets/                         ← مصدر الرسومات (يملكه Codex)
  icons/<name>.svg              ← ~40 أيقونة، شبكة 24×24
  crests/<club-slug>.svg        ← 32 شعارًا، viewBox 0 0 100 110
  brand/proki-logo.svg          ← الشعار متّجه (بدل PNG)
  brand/card-bg-*.webp          ← خلفيات الكروت (اختياري)
  preview.html                  ← لوحة معاينة لكل الأصول (للمراجعة)
  crests.json                   ← اسم النادي العربي ← slug

tools/                          ← أدوات تطوير فقط (لا يحتاجها الموقع للتشغيل)
  build-assets.js               ← يحوّل assets/*.svg ← js/generated/assets.js
  snap.js                       ← لقطات آلية للتبويبات والكروت
  lint-tokens.js                ← يعدّ: ألوان hex، إيموجي، style مضمّن

css/
  tokens.css                    ← 🆕 أول ملف يُحمّل: كل الرموز (داكن + فاتح)
  base.css, components.css      ← يُعاد بناؤها على الرموز
  ...ملفات الميزات             ← تُنظَّف تدريجيًا لتستخدم الرموز فقط

js/
  generated/assets.js           ← 🆕 مولّد، لا يُعدَّل يدويًا: ICONS{} ، CRESTS{} ، LOGO_SVG
  ui/icons.js                   ← 🆕 icon(name, {size, cls}) → <svg> ، و drawIcon(ctx,…)
  ui/crests.js                  ← 🆕 crestHTML(club,size) ، drawCrest(ctx,…) ، preloadCrests()
  ui/cards/                     ← 🆕 يحل محل canvas-cards.js
    card-kit.js                 ← القالب المشترك والمنطقة الآمنة والنصوص والتحقق
    champion-card.js, standings-card.js, standings-story.js,
    season-wrap-card.js, profile-card.js, certificate-card.js
```

### قرارات تقنية ومبرراتها

| # | القرار | البديل المرفوض | السبب |
|---|---|---|---|
| D1 | الأصول ملفات SVG في `assets/`، **وتُولَّد** منها نسخة JS (`js/generated/assets.js`) بسكربت تطوير | تحميل SVG مباشرة بـ`<img>`/`<use>` | الكروت ترسم على Canvas، وتحميل ملف خارجي من `file://` "يلوّث" الـCanvas فيفشل التصدير. نصوص SVG داخل JS تتحول لـdata URL بدون هالمشكلة. والموقع يبقى بدون خطوة بناء وقت التشغيل (الملف المولّد مُرفوع في git). |
| D2 | الأيقونات **خطية** (stroke) على شبكة 24×24، `stroke-width:1.75`، أطراف دائرية، `currentColor` | أيقونات معبّأة متعددة الألوان | تاخذ لون السياق تلقائيًا في الوضعين، وتنرسم في Canvas بـ`Path2D` مباشرة بدون تحميل صور. |
| D3 | الشعارات بقالب درع **ثابت** (مسار واحد مشترك) + طبقة نمط + رمز مركزي، بحد أقصى **3 ألوان** لكل شعار | رسومات مفصّلة | الوضوح على 24px (FR-07)، والاتساق (B-01)، وتجنّب نسخ الشعارات الرسمية (الدستور 8). |
| D4 | الكروت **داكنة دائمًا** بغض النظر عن وضع الموقع، بمقاسات 1080×1350 (منشور) و1080×1920 (ستوري) و1080×1080 (مربع) | كروت تتبع وضع الموقع، أو عرض 800px الحالي | هوية ثابتة في المجموعة، والمقاسات القياسية للواتساب والإنستغرام بدقة أعلى. |
| D5 | الرموز في `css/tokens.css` كمتغيرات CSS، ونسخة مطابقة للكروت في `card-kit.js` يتحقق منها `lint-tokens.js` | ملف رموز JSON + توليد | أبسط، وبدون خطوة بناء إضافية. |
| D6 | الانتقال **تدريجي** (Strangler): المتغيرات القديمة تصير أسماء بديلة تشير للجديدة، ثم يُحذف القديم مكوّن مكوّن | إعادة كتابة كاملة دفعة وحدة | كل PR صغير وقابل للتراجع، والموقع ما ينكسر بين المراحل. |
| D7 | قبل رسم أي كرت: `await document.fonts.load('800 40px Tajawal')` | | بدونها ممكن ينرسم الكرت بخط بديل لو الخط ما اكتمل تحميله. |

## 5. محرك الكروت (`js/ui/cards/card-kit.js`)

```js
// الواجهة المقترحة
const card = await createCard({ format: 'post' | 'story' | 'square', title, subtitle });
//  → يرسم: الخلفية، الإطار، شعار PROKI، التذييل، ويرجع منطقة آمنة:
card.safe   // {x, y, w, h}: المحتوى يُرسم هنا فقط، والتذييل خارجها دائمًا (C-01)
card.text(str, {x, y, maxW, size, weight, color, align, minSize, maxLines})  // تقليص ثم التفاف متوازن بدون كلمة يتيمة (C-03)
card.icon(name, x, y, size, color)        // Path2D من ICONS، بدون إيموجي (C-05)
card.crest(club, x, y, size)              // من CRESTS المحمّلة مسبقًا (C-06)
card.statRow([{label, value, tone}], y)   // صف الإحصاءات الموحّد
card.done()                               // → canvas

// التحقق قبل الرسم (C-02)
validateCardData(kind, data) // → [] أو قائمة نواقص: ['اسم البطل فارغ', 'الرصيد 0']
// لو فيه نواقص: ما نرسم، ونعرض للمنظّم رسالة بالنواقص بدل الكرت
```

كل كرت يصير ملف صغير (~80–150 سطر) يصف **المحتوى فقط**. القالب والخلفية والإطار والتذييل كلها في `card-kit`.

## 6. الشعارات: آلية الربط
- `assets/crests.json`: `{ "الهلال": "al-hilal", "برشلونة": "barcelona", … }` (32 مدخل).
- `crestHTML(club, size)` يحل محل `clubCrestSVG()`. وأي نادي ما له ملف يرجع لدرع احتياطي **بنفس الأسلوب** (ألوان `CLUB_STYLE` + أول حرف)، فإضافة نادي جديد ما تكسر شي.
- `CLUB_STYLE.pattern` و`monogram` يُحذفان بعد الانتقال. نُبقي `bg/fg/accent` لاستخدامها في الواجهة (مثل لون شريط النادي).
- اسم النادي تحت الدرع: سطر واحد بـ`short` (موجود في `CLUB_STYLE`) مع `text-overflow` (B-03).
