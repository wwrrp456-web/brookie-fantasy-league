## قائمة مراجعة Claude لمخرجات Codex

لكل فرع `codex/*`:
1. `git diff --stat`: هل التعديل داخل المجلدات المسموحة فقط؟
2. فحص SVG آلي: viewBox، عدد المسارات، عدد الألوان، الحجم، وعدم وجود `<image>`/base64/`<text>`.
3. لقطة `_sheet.html` على 16/24/48px، داكن وفاتح.
4. مقارنة الشعارات بالشعارات الرسمية: **أي عنصر منقول حرفيًا يرفض**.
5. قراءة `REPORT.md` وتسجيل القرارات المهمة في `plan.md`.
6. النتيجة: ✅ دمج، أو 🔁 ملاحظات محددة تُلصق لـCodex كأمر متابعة.
