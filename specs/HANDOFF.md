## 3. القرارات الأساسية (الكاملة في `decisions.md`)
| الموضوع | القرار |
|---|---|
| الجمهور | أغلب المشاركين يفتحون الموقع أسبوعيًا من الجوال، والكروت والواتساب بنفس الأهمية |
| الهدف | موقع خاص بالمجموعة، مستمر لعدة مواسم، **ومجاني بالكامل** (لا اشتراكات) |
| الميزات | **نرتّب ولا نحذف.** الثانوية تُطوى |
| الصفحة الأولى | حالتي (المركز والرصيد والحركة) ← جدول الترتيب ← أنديتي هذا الأسبوع (لاحقًا) ← بطل الجولة وقصتها ← **🥇 لوحة الميداليات ظاهرة دائمًا (R-07)** ← أقسام مطوية (لوحة الشرف وأوسمة الموسم مطويتان، R-09) |
| الهوية | شعار PROKI والكحلي والبنفسجي وخط Tajawal **معتمدة**، نطوّر عليها فقط |
| الشعارات | **نحسّن الحالية ولا نستبدلها**، ونحتفظ بالصور اللي قدّمها المنظّم. نظام مصدرين يسمح بوضع شعارات رسمية لاحقًا بقرار المنظّم |
| التنقل في الجوال | **شريط علوي** مع إشارة تمرير واضحة |
| الوضع الفاتح | نحتفظ به ونصلحه |
| اللغة | **فصحى للرسمي** (العناوين والجداول واللائحة والشهادة)، و**لهجة سعودية بيضاء** للقصص والمزاح. "الطقطقة" القوية مقبولة لكن على **الأداء فقط** |
| المعجم | **المشارك** (لا المتسابق)، و**نقاط الجولة**، و**الرصيد** (للمجموع)، و**ممة/ممّات**. أرقام لاتينية، والتاريخ ميلادي + هجري |
| الكروت | البطل، والترتيب، والستوري، وملخص الموسم، والملف الشخصي، والشهادة، + 🆕 مواجهة الجولة، + 🆕 نتائج أنديتي |
| الأمان | Firebase Rules + Auth (مجانية). **رموز المشاركين تبقى كما هي** (R-08)، ورمز المنظّم يُستبدل بحساب بريد |
| `league.html` | تتحول لصفحة تحويل إلى `index.html` (روابط قديمة في الواتساب) |
| الأدوار | **Opus:** تخطيط ومراجعة · **Sonnet:** برمجة · **Codex:** رسومات وتوليد صور (مخرجاته في `assets/` فقط) |
| الدمج | تلقائي بعد الفحص الآلي ومراجعة Opus |
