## الأدلة

- `node tests/run.js`: نجح 24 اختبارًا، دون فشل.
- فحص XML لجميع الشعارات الـ32: لا image أو text أو filter أو base64 أو بيانات محررات؛ كل ملف ضمن 8000 بايت و4 ألوان RGB كحد أقصى. معرفات فريدة ومراجع داخلية سليمة.
- الإطار والقناع الداخلي مطابقان للدفعة التجريبية. ملفات الدفعة الخمسة وmotifs وassets/crests.json مطابقة للنسخة الأساسية، والأسماء لم تتغير.
- Chromium: 32 قسمًا و384 صورة محملة دون صور مكسورة أو أخطاء JavaScript أو طلبات فاشلة. فحص عرض 390px دون تجاوز عرض الصفحة؛ مناطق المقارنة نفسها تقبل التمرير الأفقي.
- المراجعة البصرية: الأزرق يتميز بأسد تشيلسي مقابل مربعات دينامو؛ الأحمر بخطوط ميلان ومدفع أرسنال وطائر ليفربول ونسر بنفيكا وحرف H؛ دورتموند أصفر مع BVB. فُحصت المقاسات الصغيرة دون تغيير ألوان الأندية.
- اللقطة: [المقارنة الكاملة](../../assets/crests/_compare-preview.png)، والصفحة: [قبل وبعد](../../assets/crests/_compare.html).
- `tools/snap.js` و`tools/lint.js` غير موجودين في هذه النسخة؛ استُخدم فحص Chromium وXML المباشر. لم أضف أدوات برمجة للمستودع.

## قرارات اتخذتها خارج الأمر وليش

فنربخشة يستخدم أربعة ألوان نادي أصلًا: الأصفر والكحلي والأحمر والأبيض. الإطار الأسود المحايد كان سيضيف لونًا خامسًا؛ لذلك أعدت استخدام كحلي النادي في تعبئة الإطار `rgba(0,40,94,0.55)` مع حفظ الشفافية وشكل الإطار وحده الأبيض. لم تتغير ألوان النادي الأربعة أو النمط الداخلي. هذا ضبط لتعبئة الإطار لتحقيق حد الألوان، وليس اقتراح هوية بديلة.

لم أتخذ قرارات تصميمية أخرى خارج الأسلوب المعتمد، ولم أنفذ أوامر لاحقة أو أعدل ملفات الأوامر أو أنشر الموقع.
