## وش سويت
استبدلت الإيموجي بـ`iconHTML` في: `admin-auth-settings.js` (≈83 موضعًا)، `admin-round-form.js`، `admin-community-reports.js`، `admin-season-lock.js`، `admin-champion-admin.js`، `js/report/report-main.js`، و`report.html` (أيقونات ساكنة `data-icon` + تحميل `icons.css` و`assets.js` و`icon-helper.js` + `fillStaticIcons()`).

| الموضع | المعالجة |
|---|---|
| 17 حبة حالة «مفعّل/معطّل» (`updateRoundSettingsStatus`) | `innerHTML = iconHTML(الميزة) + ' مفعّل/معطّل'`: أيقونة + نص + صنف `on/off` (ليست بلون وحده) |
| رسائل `status-msg` (✅) | `iconHTML('check')` بآخر الجملة (ورثت لون الحالة) |
| أزرار (تراجع، نسخ، حذف، حفظ، فتح/طيّ كل المشاركين، إظهار/إخفاء الرموز، مختصر الجولة) | أيقونة + نص بـ`innerHTML` بدل `textContent` بالإيموجي (`savePartial`… `saveBtn` بعد الإلغاء…) |
| شارة اكتمال الجولة | `✅ مكتمل`/`⚠️ n ناقصة` ← `check`/`warning` + نص |

| **سجل النشاط القديم المخزَّن بإيموجي** (بيانات سابقة بـFirebase) | عند العرض تُحوَّل الإيموجي إلى أيقونات بـ🆕 `iconizeEmoji()` (بـ`icon-helper.js`؛ مفاتيحها بصيغة `\u{…}` فلا تُحسب إيموجي بـlint)، وما لا مقابل له يُحذف. لا تغيير بالبيانات المخزَّنة |
| `report.html`: العنوان والتبويبان وعناوين الأقسام | أيقونات ساكنة (`trophy`، `clipboard`، `target`، `check`، `edit`) |

## قاعدة 6 (لون الأيقونة بحسب الوضع) و`.ic-semantic`
- لوحة المنظّم: كل الأيقونات الزخرفية فاتحة بالليلي (لمعان > 180) وتباينها ≥ 3:1 بالوضعين (120 أيقونة بكل وضع).
- **حبوب الحالة** `.status-pill` أُضيفت لمجموعة المكوّنات المستثناة (الأيقونة بلون الحبّة: أخضر للمفعّل، ثانوي للمعطّل)؛ وكل الدلالي يبقى بوسم `.ic-semantic` عند الحاجة. القائمة بـ`css/icons.css` وبالاختبار.

## ملاحظة M83: مربع «أنديتي» الأسود (تحقّقت)

(فحصت `button svg` بالصفحة: الزر الوحيد المخالف كان هذا.)
