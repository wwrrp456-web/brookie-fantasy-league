### اتجاهات RTL

الملفات نفسها ذات اتجاه هندسي ثابت ولا تحتوي transform أو آلية انعكاس داخلية. لا يُطبّق انعكاس شامل على مكتبة SVG بسبب اتجاه الصفحة.

| الأيقونة | هل تنعكس في RTL؟ | السبب وسلوك الدمج لاحقًا |
|---|---|---|
| arrow-up | لا | صعود قيمة أو مركز؛ الأعلى يظل الأعلى |
| arrow-down | لا | هبوط قيمة أو مركز؛ لا تُقلب دلالته رأسيًا أو أفقيًا |
| trend-up | لا تلقائيًا | اتجاه عددي صاعد، وليس سهم تنقل. انعكاس الأيقونة العامة لمجرد RTL غير مطلوب؛ ترتيب الزمن في مخطط بيانات فعلي مسألة منفصلة |
| trend-down | لا تلقائيًا | اتجاه عددي هابط، بنفس قاعدة trend-up |
| chevron-left | نعم حين يُستخدم للرجوع المنطقي في واجهة RTL؛ لا إذا كان يشير إلى اليسار المكاني | الرسم المسلّم يسار فعلي. المكوّن المستهلك يختار اتجاه الرجوع/التقدم بحسب دلالته ولغة الواجهة، خارج ملف SVG. سهم إظهار الحافة اليسرى المخفية يبقى لليسار |
| chevron-down | لا | توسيع قسم إلى الأسفل؛ لا يرتبط باتجاه قراءة النص |
| share وwhatsapp-share وdownload | لا تلقائيًا | المشاركة والتنزيل أفعال ثابتة الدلالة، لا أسهم تقدم أو رجوع |

لم يُنفّذ أي تغيير في كود الدمج؛ هذه تعليمات استخدام للأصول فقط.

## الأدلة

- `node tests/run.js`: نُفّذت الاختبارات الـ24 ونجحت جميعًا، دون حالات فشل أو تخطٍّ.
- تطابق مجموعة أسماء SVG مع كل الأسماء الـ56 في BRIEF-1؛ 50 جديدة، و6 أصلية دون تغيير.
- فحص XML والسمات: جميع الملفات بسمات الجذر المطلوبة حرفيًا، وبعناصر path فقط، بلا سمات محلية تغيّر اللون أو السماكة. عدد الملفات ذات مسار واحد 10، وذات مسارين 46. لا image أو بيانات صور أو text أو فلاتر أو metadata أو بيانات محررات أو g أو transform أو معرّفات.
- فحص مساحة الأمان بطريقتين: رسم ألفا عند 600×600، ثم `getBBox()` في Chromium لكل رمز مع إضافة نصف السماكة 0.875 لكل جانب. الفحص الثاني يشمل هندسة المسار خارج مساحة العرض، ولا يعتمد على قص viewBox لإخفاء تجاوز. جميع حدود الخط داخل `[2,22]`.
- لا مسارات متطابقة بالكامل بين أيقونتين. روجعت الأشكال الستة والخمسون بصريًا عند المقاسات الثلاثة، والأزواج الحساسة في مقارنة مستقلة بالثيمين. هذا فحص بصري، لا ادعاء بدراسة تعرّف مع مستخدمين.
- صفحة العرض: 112 بطاقة و336 رسم SVG، أي 56 × 3 مقاسات × ثيمين. الأبعاد الفعلية لكل رسم مطابقة لـ16 أو24 أو48px، دون تكبير CSS للمقاس الصغير.
- Chromium على 1100px و390px: لا أخطاء JavaScript أو طلبات فاشلة أو معرّفات مكررة أو تجاوز أفقي. الألوان المحسوبة تطابق الأزواج المطلوبة، وخط Tajawal الموجود محمّل. حُجبت كل الطلبات غير المحلية في التحقق؛ لم تحاول الصفحة إجراء أي منها.
- ملفات الخطوط وترخيصها والأيقونات الستة المعتمدة لم تتغير. لا كتابة في js أو css أو index.html أو أوامر الوكلاء أو القرارات أو بقية المواصفات.
- أدوات tools/lint.js وtools/snap.js غير موجودة على فرع الأساس؛ لم يُدّع تشغيلها. فحوص SVG والمتصفح ولقطات المراجعة المذكورة مستقلة عنها.
