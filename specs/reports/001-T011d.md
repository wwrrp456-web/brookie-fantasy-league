# تقرير 001-T011d (S67): أيقونات الوضع الليلي بيضاء
**المنفّذ:** Sonnet · **الفرع:** `feat/S67-icon-dark-color` · **PR:** (في وصف الـPR) · **الحالة:** منجز · بانتظار حكم (⏹️ توقف حسب الأمر)

## المشكلة
بالوضع الليلي كانت أيقونات عناوين الطيّات (`.fold-icon{color:var(--c-brand)}`) وغيرها بنفسجية أو رمادية ثانوية (مثل النهاري)، والمنظّم يريدها بيضاء/فاتحة على الخلفية الغامقة.

## الجرد (قياس فعلي لكل أيقونة مرئية بالوضع الليلي، 390، 7 تبويبات، مشارك مختار)
قبل الإصلاح كان 70+ أيقونة بلمعان ≤ 180. جدول القرارات:

| الأيقونة / الموضع | لونها قبل | القرار |
|---|---|---|
| عناوين الطيّات `.fold-icon` (الترتيب، الجولات، الإحصائيات…) | بنفسجي `--c-brand` | **أبيض** (`--c-text`) |
| سهم الطيّة `.fold-chevron` | رمادي ثانوي `--c-text-2` | **أبيض** |
| كأس شريط حالتي `.status-bar-rank` | بنفسجي | **أبيض** |
| أيقونات «سجل ترتيبي» (`#rankHistoryBox`) | بنفسجي | **أبيض** |
| نجمة كرت «وسام جديد» | بنفسجي | **أبيض** |
| أيقونات بطاقات المشاركين (ممات/سلسلة/…) وأسئلة القواعد | رمادي ثانوي | **أبيض** |
| سهم «الأقرب للنجاة» (`bottom-race-lead`) | مرجاني (هبوط) | **يبقى دلاليًا** `.ic-semantic` |
| هدف «الجولة القادمة» (`my-dash-need`) | أخضر (صعود) | **يبقى دلاليًا** `.ic-semantic` |
| أيقونات داخل `.btn` و`.sort-mode-btn` (الزر المختار بخلفية ذهبية) و`.status-msg` | لون نص المكوّن فوق خلفية مملوءة | **تبقى بلون المكوّن** (استثناء مكوّنات موثّق) |

## وش سويت
- `css/icons.css`: قاعدة وحيدة بالوضع الليلي فقط: `html:not(.light-mode) .ic:not(.ic-semantic):not(.btn .ic):not(.sort-mode-btn .ic):not(.status-msg .ic){color:var(--c-text)}` + `.fold-icon/.fold-chevron`. **النهاري كما هو (لم يُمَس).**
- وسم `.ic-semantic` (عبر `iconHTML(name,{cls:'ic-semantic'})`) على الدلاليتين فقط؛ كل ما عداهما زخرفي يتبع النص. أيقونات المنظّم (S59) والتبويبات الأخرى (S60) ستستفيد تلقائيًا بعد استبدالها بـ`iconHTML`، وتُوسَم الدلالية منها هناك.
- 🆕 تقوية `tests/e2e/icon-theme-color.e2e.js`: بالليلي كل أيقونة زخرفية لمعانها > 180 (139 أيقونة)، والمستثنى صراحةً بالدلالي (`.ic-semantic`) أو مكوّنات الأزرار/الحالة بسبب مكتوب بالاختبار؛ وبالنهاري لا أيقونة زخرفية بيضاء. كل الفحوص ✅.
